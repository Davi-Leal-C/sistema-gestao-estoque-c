##  Visão Geral e Contexto
Este projeto é uma aplicação de terminal desenvolvida em C para gerenciamento e controle de estoque. O principal problema que ele resolve é a persistência de dados de forma simples e eficiente, permitindo registrar entradas e saídas de produtos e salvando essas informações de forma automática em um arquivo de texto local (`relatorio_estoque.txt`). 

Projeto prático desenvolvido durante o 2º semestre do curso de Engenharia de Software.

##  Tecnologias Utilizadas
- **Linguagem:** C
- **Conceitos Aplicados:** Estruturas de controle, manipulação de arquivos (File I/O) e estruturação de variáveis.
- **Ambientes de Desenvolvimento:** Dev-C++ / Visual Studio Code.
